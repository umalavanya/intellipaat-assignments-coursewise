TASK MANAGER API - POSTMAN ENDPOINTS
====================================

Base URL
--------
http://localhost:4000

Common headers for JSON requests
---------------------------------
Content-Type: application/json


1. HEALTH CHECK
---------------
Method: GET
URL: http://localhost:4000/api/test
Authorization: Not required

Expected response:
{
  "message": "Server is running!"
}


2. ROOT CHECK
-------------
Method: GET
URL: http://localhost:4000/
Authorization: Not required

Expected response:
Task Manager API is running


3. REGISTER USER
----------------
Method: POST
URL: http://localhost:4000/api/auth/register
Authorization: Not required
Headers: Content-Type: application/json

Body -> raw -> JSON:
{
  "name": "John Doe",
  "email": "john@example.com",
  "password": "123456"
}

Protected task endpoints
------------------------
For the following endpoints, use this header:
Authorization: Bearer YOUR_TOKEN_HERE
Content-Type: application/json

Replace YOUR_TOKEN_HERE with the token returned by registration or login.


5. CREATE TASK
--------------
Method: POST
URL: http://localhost:4000/api/tasks
Authorization: Required
Headers:
Authorization: Bearer YOUR_TOKEN_HERE
Content-Type: application/json

Body -> raw -> JSON:
{
  "title": "Learn Node.js",
  "description": "pending"
}

Allowed description values: pending, completed
6a91ae6f2abd1be83246f5cf



6. GET ALL USER TASKS
---------------------
Method: GET
URL: http://localhost:4000/api/tasks
Authorization: Required
Headers:
Authorization: Bearer YOUR_TOKEN_HERE

Returns tasks belonging to the logged-in user.


7. UPDATE TASK
--------------
Method: PUT
URL: http://localhost:4000/api/tasks/TASK_ID
Authorization: Required
Headers:
Authorization: Bearer YOUR_TOKEN_HERE
Content-Type: application/json

Replace TASK_ID with the _id returned when creating a task.

Body -> raw -> JSON:
{
  "title": "Learn Express.js",
  "description": "completed"
}


8. DELETE TASK
--------------
Method: DELETE
URL: http://localhost:4000/api/tasks/TASK_ID
Authorization: Required
Headers:
Authorization: Bearer YOUR_TOKEN_HERE

Replace TASK_ID with the task _id.

Expected response:
{
  "message": "Task removed"
}


Recommended testing order
-------------------------
1. GET /api/test
2. POST /api/auth/register
3. POST /api/auth/login
4. POST /api/tasks
5. GET /api/tasks
6. PUT /api/tasks/TASK_ID
7. DELETE /api/tasks/TASK_ID


Important startup note
----------------------
If the server fails while loading models/Task.js, make sure the description
field includes its Mongoose type:

description: {
  type: String,
  enum: ['pending', 'completed'],
  default: 'pending'
}
