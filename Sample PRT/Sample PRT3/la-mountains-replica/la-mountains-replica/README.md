# LA Mountains — Front-end replica

This is a responsive front-end recreation of the supplied `full-stack-prt.netlify.app` page.

## Run
No build step is required.

Open `index.html` directly in a browser, or serve the folder with any static server.

Example:
```bash
npx serve .
```

## Notes
- The layout, typography, section structure, carousel behavior, responsive tabs, and footer are recreated in plain HTML/CSS/JS.
- Image assets are referenced from the supplied public website so the replica stays lightweight.
- The source page exposes a hero, History carousel, Climb tabs, and copyright footer.
